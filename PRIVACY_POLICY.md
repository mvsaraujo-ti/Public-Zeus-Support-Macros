# Privacy Policy – Zeus Support Macros

Last updated: 26 November 2026

Zeus Support Macros is a browser extension developed to improve productivity within the Interact TJMA system.

## 1. Data Collection

Zeus Support Macros does NOT collect, transmit or store personal data on any external server.

To work, the extension reads, locally in your browser, the text of the chat that is open in Interact (messages, and the name, registration number or phone number that appear in it) in order to build a summary and fill templates. This content is processed only in the browser tab, is never sent anywhere, and is not accessible to the developer.

The extension does not gather:
- Authentication credentials
- Browsing history
- Analytics data
- Tracking information

## 2. Local Data Storage

Macros, Mini Wiki articles and settings are stored locally in the browser (localStorage of the Interact page). When the user clicks "Abrir no GLPI e preencher", a draft of the ticket (title, description, phone) is placed in the extension's local storage (chrome.storage.local) only so the GLPI form page can read it; it expires after 30 minutes and is deleted as soon as the form is filled.

This data:
- Remains exclusively on the user's device
- Is not transmitted to any external server
- Is not accessible by the developer
- Is not shared with third parties

## 3. Permissions

The extension operates exclusively on the following domains:

https://interact.tjma.jus.br/* (reading the open chat to build the summary, inserting text into the message box)
https://atendimento.tjma.jus.br/Form/Render/* (only to fill the ticket form fields when the user asks; it never submits the form)

It does not access or interact with other websites.

## 4. Third-Party Services

Zeus Support Macros does not integrate with any third-party APIs, analytics services, or external tracking systems.

## 5. Data Security

Since no external data transmission occurs, all information remains confined to the local browser environment.
